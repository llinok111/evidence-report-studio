# 汽车新媒体投流的规模与自研工具

> 核心判断：投流 agent 的价值不在「比人聪明」，而在「能看的时间窗口比人长一个数量级」。这是可验证的能力差，不是玄学。

### 2.1 消耗规模

他给了一个很少见的自曝口径。个人层面：他自称投手出身，去年个人投放量在 8000 多万、8500 万左右，并强调这是个人消耗、跟团队无关 [7699100533977582374-0311]。团队层面：去年的总消耗是「1 6 亿」（原文如此，转录未区分小数点位置，口径存疑，不做换算），去年服务了 2000 多家汽车垂直投放 [7699100533977582374-0312]。

这两个数字要分开看。8500 万是个人业绩，2000 多家是团队覆盖——一个人的消耗能到团队总盘的一半量级，说明这门生意的产能高度集中在少数投手身上。这也解释了为什么他会去做 agent：瓶颈在人。

### 2.2 投流 agent 的价值主张

真正的差异点在数据窗口。人工投手能看的是「几条计划 或者近三天 近五天的一个计划 近七天的计划」，而 AI 可以抓过往一个月、两个月、三个月，精确到某一条计划、某一个素材、某一个节点 [7699100533977582374-0402]。

这是一个可验证的能力差，不是「AI 更聪明」这种空话。人脑处理不了三个月的素材级时序数据，工具可以。所以投流 agent 的定位应该是**把决策依据的时间窗口拉长**，而不是替代投手的判断。

他对替代边界的表述是「现在它的能力已经慢慢逼近甚至超越我们的顶级投手了」[7699100533977582374-0405]（个人判断，非客观事实）。这句话的可信度需要打折——说话人自己就是这套工具的开发者与销售方。

产品状态也需要看清：投流 agent「这个还没 开发好 但是已经在跑数据了」[7699100533977582374-0244]。也就是说，目前能对外讲的是数据能力，不是成品。

对未来的预期他自己给了一个数：agent 出来之后，「至少能卖100个客户以上」[7699100533977582374-0313]（这是他本人的预测，不是已发生的事实）。

还有一个值得记下的角色变化：原来是他指挥工具，现在变成工具指导他去做创意和需求挖掘 [7699100533977582374-0386]（个人判断）。这个转换如果成立，投手的核心能力会从「会操作」迁移到「会提问」。
